# Canvas Design

Create beautiful visual art in `.png` and `.pdf` documents using design philosophy.

## What It Does

This skill guides agents through a two-phase creative process for producing high-quality visual artwork. First, it generates a unique design philosophy — an aesthetic manifesto describing how form, space, color, and composition should be expressed. Then, it translates that philosophy into a museum-quality canvas artifact (PDF or PNG), emphasizing expert craftsmanship, minimal text, and spatial storytelling.

Use this skill when the user asks to create a poster, piece of art, visual design, or any other static visual piece.
