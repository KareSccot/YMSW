# Adding E2E Tests

Set up Playwright end-to-end testing.

## What It Does

Guides setting up Playwright for end-to-end testing. Covers: installation, configuration, page object pattern, writing tests with role-based locators, handling authentication, running in CI, and debugging with trace viewer.

## Source

Based on community patterns from [awesome-cursor-skills](https://github.com/spencerpauly/awesome-cursor-skills) (MIT License).

## Tags

`agentic-sdlc` · `phase:4_test` · `testing`

## Risk Flags

- `runs_scripts`: true — installs Playwright and runs browser tests
- `external_deps`: true — depends on Playwright and browser binaries
