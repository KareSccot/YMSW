# Writing Plans

Write comprehensive implementation plans with bite-sized tasks.

## What It Does

Creates detailed implementation plans assuming the engineer has zero codebase context. Each task is 2-5 minutes, contains exact file paths, complete code blocks, test commands with expected output, and commit messages. Enforces DRY, YAGNI, TDD, and frequent commits. No placeholders ever.
