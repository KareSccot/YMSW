# XLSX

Create, read, edit, and manipulate spreadsheet files.

## What It Does

This skill provides comprehensive guidance for working with spreadsheet files (`.xlsx`, `.xlsm`, `.csv`, `.tsv`). It covers professional formatting standards (font choices, number formats, color coding for financial models), formula construction rules (assumptions placement, error prevention, documentation), and practical workflows for reading, editing, and creating spreadsheets. The skill enforces zero formula errors and industry-standard conventions for financial models, including blue-text inputs, parenthesized negatives, and proper unit labeling.

Use this skill any time a spreadsheet file is the primary input or output — whether opening, editing, creating, cleaning, or converting tabular data.
