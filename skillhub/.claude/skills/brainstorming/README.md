# Brainstorming

Socratic design exploration before implementation.

## What It Does

This skill activates before any creative work — creating features, building components, adding functionality, or modifying behavior. It explores user intent, requirements, and design through natural collaborative dialogue before any code is written.

The process: explore project context, ask clarifying questions one at a time, propose 2-3 approaches with trade-offs, present design in sections for validation, write spec document.
