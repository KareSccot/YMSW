# CI/CD 知识库 - AI 版

## 概览
本知识库涵盖 CI/CD 流水线的接入、配置、日常操作、故障排查和合规要求。
基于 `cicd-template`、`gitlab-management` 和 `team-cicd` 三个仓库的知识提取。

## 文件结构
- **00-前置条件.md**：接入 CI/CD 的前置条件、项目配置要求、GitLab 项目管理入门、Team-CICD 团队层接入
- **10-新手接入指南.md**：新手接入流水线、构建工具配置、Docker 镜像构建、K8s/VM 部署、团队自定义工作流配置
- **20-日常开发与发版.md**：日常开发流程、发版流程、UAT 部署、流水线管理、FAQ、团队特定部署策略
- **30-故障排查.md**：流水线启动失败、构建失败、部署失败、安全扫描问题、团队层配置问题
- **40-合规须知.md**：发版审批要求、安全扫描要求、敏感信息管理规范、团队镜像构建规范

## 文档类型
- **procedure**：接入指南、配置、部署、发版、流水线管理、团队工作流配置
- **faq**：常见问题 Q&A
- **troubleshooting**：故障诊断和解决
- **policy**：合规和安全政策

## 三层架构
```
Common 层: devops/cicd-template          ← 通用工作流模板
   ↓ 引用
Team 层:  <team>/team-cicd               ← 团队级配置（自定义变量、标签、策略）
   ↓ 引用
App 层:  <team>/<app-repo>               ← 应用项目（仅需 .gitlab-ci.yml 引用）
```
