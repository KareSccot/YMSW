# 前置条件

## 目标
读完本章后，开发者能了解接入 CI/CD 所需的前置条件、权限要求和准备工作。

## 前置条件
- 项目已在 GitLab 实例上创建
- 开发者拥有至少 Developer 角色
- 项目负责人已确定团队名和部署类型

## 操作步骤
1. 确认项目 GitLab 地址
2. 确定项目所属团队（Team）和部署环境（dev / uat / prod）
3. 选择构建工具类型（Gradle / Maven / pnpm / Docker）
4. 在项目根目录创建 `.gitlab-ci.yml` 文件
5. 引用 Common 层 CI/CD 工作流模板
6. 提交代码并推送至远程仓库

## 注意事项
- 项目必须托管在 GitLab 实例上
- 构建工具类型必须提前确定，否则流水线无法正确配置
- 首次接入建议联系 DevOps 团队获取指导

## 升级路径（搞不定找谁）
- 项目权限问题 → 联系项目负责人或团队 Tech Lead
- 部署环境配置 → 联系对应环境负责人
- 接入指导 → 联系 DevOps 团队 `#devops-support`
