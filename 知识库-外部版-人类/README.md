# CI/CD 知识库 - 人类版

## 使用说明
本知识库面向外部开发者，按开发旅程组织，从入门到日常操作到故障排查。

## 文件结构
- **00-前置条件.md**：了解接入 CI/CD 需要准备什么
- **10-新手接入指南.md**：一步步接入 CI/CD 流水线
- **20-日常开发与发版.md**：日常开发操作和发版流程
- **30-故障排查.md**：常见问题诊断和解决
- **40-合规须知.md**：审批、安全和合规要求

## 阅读顺序
新手建议按编号顺序阅读：
00 → 10 → 20 → 40 → 30（遇到问题时查阅）

## 注意
- 本知识库不包含内部实现细节
- 操作步骤中的角色名指代具体团队（如 DevOps 团队、安全团队）
- 遇到问题时先查阅 30-故障排查.md，如无法解决按升级路径联系对应团队
