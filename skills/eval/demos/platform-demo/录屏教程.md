# 平台工程师维护录屏教程

> 照此文档一步步操作，录制 platform-engineer skill 的平台维护过程。
> 前置已就绪：platform-engineer skill 已装到 `C:\Users\jiang.ke\.claude\skills\platform-engineer\`，PowerSession.exe 在 `C:\Users\jiang.ke\bin\`。
> 演示场景：Java 团队要 JDK 21 镜像，当前 catalog 只到 JDK 17。平台工程师从进入 skill → 提问协议定位 → 按同步清单改文件 → 跑回归脚本，完整走一遍。

---

## 第 1 步：开终端

打开 **PowerShell**（开始菜单搜 PowerShell）。

## 第 2 步：进入 skill 仓库目录

```
cd C:\Users\jiang.ke\Desktop\internJ\skills
```

> 在这里录，因为要展示改 maintain/ 真源文件 + 跑 regression-check.sh。

## 第 3 步：开始录屏

```
C:\Users\jiang.ke\bin\PowerSession.exe rec platform-demo.cast
```

PowerSession 会起一个子 shell（提示符变了 = 正在录）。

## 第 4 步：在录屏 shell 里启动 Claude Code

```
claude
```

## 第 5 步：触发 platform-engineer skill

在 Claude Code 里输入这句话：

```
我要维护 CI 模块，Java 团队需要 JDK 21 镜像，当前 base-image-catalog 只到 JDK 17，要加一个
```

Claude 会自动激活 platform-engineer skill，进入平台维护入口。

## 第 6 步：提问协议 —— 选维护类型

Claude 会问你要维护什么（3 选项）。它应该自动识别出是 CI 维护（base-image 更新）。如果它问，选 **1. CI（持续集成）**。

## 第 7 步：CI 提问协议 —— 选子类型

Claude 进入 CI 场景后，会问属于哪类维护（A/B/C/D）。选 **A. base-image-catalog 更新**。

## 第 8 步：Claude 定位文件 + 给同步清单

Claude 会按提问协议：
1. 问你新增还是废弃（回答：新增，版本号 JDK 21，镜像名 devops/jdk21_maven3.9.6）
2. Read `maintain/resources/references/base-image-catalog.md` §B（五步走）
3. 给你文件同步清单：

| 文件 | 改什么 |
|---|---|
| `maintain/resources/references/base-image-catalog.md` §A | 加 JDK 21 行 |
| `maintain/capabilities/ci/gitlab-ci-gen.md` Batch 3 Q8 | 编译镜像选项加 JDK 21 |
| `maintain/capabilities/ci/gitlab-ci-gen.md` Batch 3 Q9 | 运行时镜像选项加 JDK 21 |
| `maintain/resources/templates/gitlab-ci.minimal.yml` | 注释镜像示例更新 |

让它展示完这个清单。

## 第 9 步：看 Claude 执行变更

让 Claude 按同步清单逐个文件改。它会 Read 每个文件确认当前位置 → 改 → 报告改了什么。

让它改完 3 个 maintain/ 文件（catalog §A + gitlab-ci-gen Q8/Q9 + 模板注释）。

> 录屏里不用真改全部，让它改 catalog §A 加一行 + gitlab-ci-gen Q8 加一个选项就够了，展示"按同步清单逐文件改"这个动作。

## 第 10 步：跑回归脚本

变更完后，让 Claude 跑回归：

```
跑回归检查
```

Claude 应该执行：

```
bash maintain/regression-check.sh
```

看到输出 5 项检查全绿（✓ 所有检查通过，无错误）。

## 第 11 步：看 Claude 报回

Claude 会做收尾报告：改了哪些文件 + 回归结果 + 不 commit 等验收。等它说完。

## 第 12 步：退出 Claude Code

```
exit
```

## 第 13 步：退出 PowerSession 录屏

回到 PowerSession 子 shell：

```
exit
```

录屏结束，platform-demo.cast 已生成在 skills 目录。

## 第 14 步：回放检查

```
C:\Users\jiang.ke\bin\PowerSession.exe play platform-demo.cast
```

看一遍录的内容对不对（提问协议定位 → 同步清单 → 逐文件改 → 回归脚本全绿 → 收尾）。

## 录屏要展示的重点

这录屏跟昨天 user 侧的区别：
- **昨天 user 侧**：从零接入一个项目（Step0 初始化 → Batch 提问 → 生成 CI 文件）
- **今天平台侧**：维护已有 skill 体系（进 SKILL.md → 提问协议自动定位到具体文件段落 → 同步清单跟着走 → 跑自动化回归）

重点展示平台工程师**不用翻目录**——提问协议直接告诉他改哪个文件的哪一段。

## 如果卡住

- PowerSession 报 PermissionDenied：cd 到 skills 目录（有写权限）再录
- Claude 不激活 skill：确认说的是「维护 CI 模块」触发词，skill 装在 `C:\Users\jiang.ke\.claude\skills\platform-engineer\`
- regression-check.sh 跑不起来：确认在 skills 目录下，脚本在 `platform-engineer/maintain/regression-check.sh`
- 任何问题随时在 #CICD知识库小组 线程问
