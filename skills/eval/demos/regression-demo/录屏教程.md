# 回归门控演示录屏教程

> 照此文档一步步操作，录制 platform-engineer skill「故意断链 → 回归报错 → 修复 → 全绿」的完整过程。
> 展示 skill 的核心价值：改完跑回归门控，机械校验抓出断链，修完再跑全绿。

---

## 前置已就绪

- 干净 demo 副本在 `C:\Users\jiang.ke\Desktop\internJ\regression-demo\`（从 skills 仓库复制，不影响真源）
- `PowerSession.exe` 在 `C:\Users\jiang.ke\bin\`
- 回归脚本在 `regression-demo\platform-engineer\maintain\regression-check.sh`
- 基线状态：7/7 全绿（已验证）

---

## 第 1 步：开终端

打开 **PowerShell**（开始菜单搜 PowerShell）。

## 第 2 步：进入 demo 目录

```
cd C:\Users\jiang.ke\Desktop\internJ\regression-demo\platform-engineer
```

## 第 3 步：开始录屏

```
C:\Users\jiang.ke\bin\PowerSession.exe rec regression-demo.cast
```

PowerSession 会起一个子 shell（提示符变了 = 正在录）。

## 第 4 步：先跑一次基线（展示全绿）

在录屏 shell 里跑：

```
bash maintain/regression-check.sh
```

应该看到 7 项检查全 `✓`，结尾 `✓ 回归检查执行完毕`。
这一步让观众知道：**正常状态是全绿的。**

## 第 5 步：故意断链——删一个能力模块文件

模拟平台工程师重组目录时误删了一个模块文件：

```
rm maintain/capabilities/vm/verify.md
```

（这是 VM 验证模块，能力表里引用了它，删掉就断链了。）

## 第 6 步：跑回归——展示报错

```
bash maintain/regression-check.sh
```

这次会看到两条报错：
- `❌ 路径不存在: maintain/capabilities/vm/verify.md`（第 1 项 路径可达性）
- `⚠ 悬空引用: capabilities/vm/verify.md 在能力表中但文件不存在`（第 6 项 结构一致性）

**这一步是演示重点：回归门控机械抓出了断链，不用人工逐个翻文件。**

## 第 7 步：修复——把文件还原

demo 副本不带 git，直接从真源拷回来：

```
cp ..\..\..\skills\platform-engineer\maintain\capabilities\vm\verify.md maintain\capabilities\vm\verify.md
```

确认文件回来了：

```
ls maintain/capabilities/vm/verify.md
```

## 第 8 步：再跑回归——展示全绿

```
bash maintain/regression-check.sh
```

这次 7 项全 `✓`，结尾 `✓ 回归检查执行完毕`。
**修复后回归门控确认全绿，可以放心 commit。**

## 第 9 步：退出录屏

回到 PowerSession 子 shell，输入：

```
exit
```

录屏结束，`regression-demo.cast` 文件已生成在 `platform-engineer` 目录。

## 第 10 步：回放检查

```
C:\Users\jiang.ke\bin\PowerSession.exe play regression-demo.cast
```

看一遍录的内容对不对（基线全绿 → 删文件 → 回归报两条错 → 还原文件 → 回归全绿）。

把 `regression-demo.cast` 文件位置告诉我，我用 agg 转成 GIF 交付。

## 如果卡住

- PowerSession 报 PermissionDenied：cd 到 demo 目录（有写权限）再录
- `bash` 命令找不到：用 Git Bash 而不是 PowerShell，或在 PowerShell 里跑 `"C:\Program Files\Git\bin\bash.exe" maintain/regression-check.sh`
- 第 7 步 cp 还原报错：确认路径 `..\..\..\skills\platform-engineer\maintain\capabilities\vm\verify.md` 存在（真源在那）
- 任何问题随时在 #CICD知识库小组 线程问
