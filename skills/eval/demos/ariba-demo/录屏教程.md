# ariba-srmp-ui 接入录屏教程

> 照此文档一步步操作，录制 user-cicd skill 从零接入 ariba-srmp-ui 的完整过程。
> 前置已就绪：user-cicd skill 已装到 `C:\Users\jiang.ke\.claude\skills\cicd\`，PowerSession.exe 在 `C:\Users\jiang.ke\bin\`，已备好 ariba 真实源码的干净副本 `ariba-clean-demo`（全新 git 只有一个 init commit、无 CI 文件、无 remote，Claude 不会看穿已接入也不会连远端）。

---

## 第 1 步：开终端

打开 **PowerShell**（开始菜单搜 PowerShell）。

## 第 2 步：进入干净副本目录

```
cd C:\Users\jiang.ke\Desktop\internJ\ariba-clean-demo
```

## 第 3 步：开始录屏

```
C:\Users\jiang.ke\bin\PowerSession.exe rec ariba-demo.cast
```

PowerSession 会起一个子 shell（提示符变了 = 正在录）。

## 第 4 步：在录屏 shell 里启动 Claude Code

```
claude
```

## 第 5 步：触发 user-cicd skill

在 Claude Code 里输入这句话：

```
帮我接入 CICD，项目 ariba-srmp-ui，前端 Vue 走 ArgoCD 部署，新项目从零接入
```

Claude 会自动激活 cicd skill，进入 user-cicd 流程。

## 第 6 步：Step 0 初始化引导 —— 照抄应答

Claude 问 4 个问题，照下表回答：

| 问题 | 回答 |
|---|---|
| 项目名 | `ariba-srmp-ui` |
| 语言栈 | `前端 Vue` |
| 部署目标 | `ArgoCD` |
| 项目状态 | `新项目，从零接 CI` |

## 第 7 步：前置收集 —— 照抄应答

| 参数 | 回答 |
|---|---|
| ENV_PREFIX | `UAT_` |
| DEPLOY_USER | `appdeploy` |

## 第 8 步：选流程

Claude 给 3 个选项，选 **2. 生成 CI 配置文件**。

## 第 9 步：Batch 1（项目结构 + 部署目标）—— 照抄应答

| 题 | 回答 |
|---|---|
| 1. 项目类型 | `A. 单服务` |
| 2. 服务标识 SERVICE_NAME | `ariba-srmp-ui` |
| 3. 部署目标环境 | `D. 仅 ArgoCD（无 VM 部署）` |
| 4. 部署方式 | `B. ArgoCD / K8s` |

## 第 10 步：Batch 2（语言 + 构建方式 + Dockerfile 模式）—— 照抄应答

| 题 | 回答 |
|---|---|
| 5. 语言 + 构建工具 | `D. Node + npm` |
| 6. 构建产物怎么出 | `A. CI 独立 build-app job 编译` |
| 7. Dockerfile 模式 | `B. 简单（FROM 写死）` |

## 第 11 步：Batch 3（镜像选型）—— 照抄应答

| 题 | 回答 |
|---|---|
| 8. 编译环境镜像 | `E. node18_npm9.8.1` |
| 9. 运行时基础镜像 | `nginx:1.29.4-alpine` |

## 第 12 步：Batch 4（SSL）—— 照抄应答

| 题 | 回答 |
|---|---|
| 10. SSL 怎么处理 | `A. 上游 LB/Ingress 终止 SSL` |

## 第 13 步：看 Claude 生成文件

收齐 10 个参数后，Claude 会 Read 模板生成 3 个文件到 ariba 仓库根：
- `.gitlab-ci.yml`
- `Dockerfile`
- `nginx.conf`

让它生成完，看到它报告"3 个文件已生成"。

## 第 14 步：收尾

Claude 会做 Step 3 收尾报告（做了什么、还差什么、下一步）。等它说完。

## 第 15 步：退出 Claude Code

在 Claude Code 里输入：
```
exit
```

## 第 16 步：退出 PowerSession 录屏

回到 PowerSession 子 shell，输入：
```
exit
```

录屏结束，ariba-demo.cast 文件已生成在 ariba-clean-demo 目录。

## 第 17 步：回放检查

```
C:\Users\jiang.ke\bin\PowerSession.exe play ariba-demo.cast
```

看一遍录的内容对不对（Step0 提问应答 → Batch1-4 → 生成 3 文件 → 收尾）。

## 录完之后

把 ariba-demo.cast 文件位置告诉我，或回放没问题就说一声。
原 ariba-srmp-ui 仓库的 CI 文件我会自己还原（你不用管，你只在 ariba-clean-demo 副本里录）。

## 如果卡住

- PowerSession 报 PermissionDenied：在当前目录没写权限，cd 到 ariba 仓库目录（有写权限）再录
- Claude 不激活 skill：确认说的是「接入 CICD」触发词，skill 装在 `C:\Users\jiang.ke\.claude\skills\cicd\`
- 找不到 claude 命令：Claude Code CLI 没装或不在 PATH
- 任何问题随时在 #CICD知识库小组 线程问
