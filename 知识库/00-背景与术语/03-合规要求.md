# 合规要求

## 目标

说清公司 CI/CD 与 AI 使用相关的合规边界：谁能用 AI、必须用什么模型、数据出口限制、外包限制。各角色操作前须知。

## AI 使用边界

| 对象 | 能否用 AI 辅助开发 | 说明 |
|---|---|---|
| 内部开发 | ✅ 允许 | 公司内部开发人员可用 AI 辅助写代码（Claude Code/Cursor/Copilot 等工具） |
| 外包人员 | ❌ 禁止 | 会议明确"禁止 AI 代码开发"禁令针对外包。外包不得用上述工具写代码 |

> 这条边界由平台管理员/团队 Lead 在开 GitLab 账号、加 Group 成员时把关：给外包开账号须遵守此边界，权限宜只读或受限。

## 数据出口与模型要求

**必须用公司内部模型，不允许公网 Claude/Anthropic API**——数据出口合规要求。

| 要求 | 说明 |
|---|---|
| 内部模型 | GLM-5.1 / DeepSeek V4 等公司内部模型 |
| 禁止公网 API | 不允许用公网 Claude / Anthropic API（数据出口合规） |
| 获取 API Key | 通过 `aisix-mgmt` 注册入驻（`POST /api/v1/onboarding` 一键拿 Key，见 `06-aisix-mgmt接口`） |
| 默认模型 | 入驻时默认分配 DeepSeek，可按需指定其他已注册模型 |

> 即使用 AI 工具（如 Claude Code），其后端模型配置也须指向公司内部模型，不能配公网 Anthropic API key。

## 内部模型清单

会议提及的内部模型（以实际可注册为准，可用 `aisix-mgmt 接口 4` 查最新可用列表）：

| 模型 | 来源 | 备注 |
|---|---|---|
| GLM-5.1 | 公司内部 | 会议提及，Daryl 的 Skill 跑在此模型上 |
| DeepSeek | 公司内部 | aisix-mgmt 入驻默认模型（`AI_GATEWAY_DEFAULT_MODELS=deepseek`） |

> 实际可用模型清单以 `aisix-mgmt` 的 `GET /api/v1/environments/{env_id}/models` 返回为准（过滤 `kind == "routing"` 的）。

## CI/CD 相关合规注意

| 项 | 要求 | 出处 |
|---|---|---|
| 审批门禁 | 发版须过 `approval` + `appsec_approval`，靠 stage 顺序实现，不可绕过 | 「场景 05」 |
| 镜像发版 | Build Once Promote Many——发版镜像须是主干已构建并过 UAT 的，不重新构建 | 「场景 04」 |
| 敏感信息 | SSH 私钥/SSL 证书/密码等用 GitLab CI/CD Variables（Protected + Masked），不由开发者管 | 「场景 06」 |
| Common 层改动 | 影响 全公司业务线，须更高治理审批，不走普通 MR | 「Common 层」 |
| gitlab-management 部署 | 无鉴权 + CORS 全开，须内网部署不暴露公网 | 「平台管理员」 |

## 代码示例

```bash
# 注册拿内部模型 API Key（合规要求：用此 Key，不用公网 Claude API）
TOKEN=$(curl -s -X POST http://<aisix-host>:5000/api/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{"client_id":"admin","client_secret":"<凭证>"}' | python -c "import sys,json;print(json.load(sys.stdin)['token'])")

curl -X POST http://<aisix-host>:5000/api/v1/onboarding \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"email":"dev@wuxibiologics.com","team":"后端开发","user_name":"张三"}'
# 响应里的 api_key 即内部模型调用凭证
```

## 注意事项

- **外包禁令是硬要求**：给外包开 GitLab 账号、加 Group 成员时须确保不授予用 AI 写代码的权限/环境。
- **数据出口合规**：任何把代码/数据发到公网 AI API 的行为都违反此要求。AI 工具的模型后端须配公司内部模型。
- **API Key 明文只返回一次**：aisix-mgmt 入驻时务必保存好返回的 `api_key`，Key 已存在后无法再次获取明文。
- **生产环境改凭证**：aisix-mgmt 默认 `admin:admin123`，生产环境必须改强密码（见 `aisix-mgmt 安全`）。
- **门禁不可绕过**：审批门禁靠 stage 顺序，绕过即违规（见「场景 05 审批门禁与注意事项」）。
