# CI/CD 知识库（外部版 · 人类阅读）

面向使用公司 CI/CD 体系的应用开发者，覆盖项目接入到生产发版完整链路。内容由 `devops/cicd-template`、`devops/team-cicd`、`devops/gitlab-management` 三个仓库源文件提取并脱敏生成。更新于 2026-09-09，本次更新：新增 ariba 前后端与 isrm-appsec 团队工作流配置参考，新增跨仓 include 关联说明。

## 文档导航

| 文件 | 读完能做什么 |
|------|--------------|
| [00-前置条件与总览](00-前置条件与总览.md) | 理解 CI/CD 三层架构、流水线阶段、所需权限与角色 |
| [10-新手接入指南](10-新手接入指南.md) | 把一个新项目接入 CI/CD 流水线并跑通首次构建 |
| [20-日常开发与发版](20-日常开发与发版.md) | 日常提交、MR、部署、发版的操作与状态查看 |
| [30-故障排查](30-故障排查.md) | 诊断构建失败、部署失败、安全扫描失败等常见故障 |
| [40-合规须知](40-合规须知.md) | 知晓安全合规红线、审批门禁、镜像合规要求 |

## 建议阅读顺序

新接入项目的开发者按编号顺序通读：先读 00 建立架构认知 → 10 完成接入 → 20 掌握日常 → 30 备查故障 → 40 牢记红线。已有项目接入经验者可按需直接查阅对应文件。

## 符号约定

- `<占位符>`：尖括号为需替换的实际值，如 `<team-branch>` 替换为团队分支名
- `变量名`：反引号为 CI/CD 变量或配置项名
- 流水线阶段名用代码标注，如 `build` / `deploy-prod`
